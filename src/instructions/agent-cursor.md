# Особенности cursor

- Headless из shell-сессии не авторизован (нужен `agent login` или
  `CURSOR_API_KEY`): живая проверка — только из GUI-терминала пользователя.
- Канала hooks у CLI нет (`cursor-agent --help`): подмешать что-либо в контекст
  сессии нечем, весь durable-контекст приходит сводом правил и навыками.
