# Особенности omp

- Имя исполнителя — Oh My Pi, коротко `omp`; для `PROTOCOL_AGENT` и имени
  справочника — `omp`. Имя сообщено в системном промпте сессии (проверено:
  «working in Oh My Pi coding harness»). Программный маркер сессии omp —
  переменная `OMPCODE=1` (проверено `printenv`).
- `AGENT_SKILLS_DIR` в окружении сессии не задан (проверено `printenv`).
  Фермы навыков в домашних каталогах CLI идентичны. Источник навыка получай
  realpath'ом загруженного `SKILL.md`, а не каталогом установки.
- Конфиг станции — `~/.omp/agent/config.yml`: роли моделей (`modelRoles`),
  советник, память, поведение редактора. Домашний каталог omp — `~/.omp`.
  Изоляция слоя — `--profile` (отдельные auth, sessions, settings и caches,
  проверено `omp --help`) и разовый оверлей `--config`; роли моделей
  переопределяются env `PI_SMOL_MODEL`, `PI_SLOW_MODEL`, `PI_PLAN_MODEL`.
- `bash` исполняется в постоянном процессе, но рабочий каталог между вызовами
  не сохраняется (проверено: после `cd` в вызове следующий `pwd` показывает
  стартовый каталог сессии). Каталог задавай параметром вызова или `cd`
  внутри самой команды; при неожиданном результате проверяй `pwd`.
- Песочницы нет: запись в `$HOME` вне рабочего дерева прошла
  (проверено пробой `touch` + `rm`), `/bin/ps` исполняется (проверено:
  `ps -p 1` → `launchd`), поэтому каналы живости и уборки на `ps` допустимы.  
- Правку файла делает `edit` после того, как файл прочитан `read` в контексте;
  правка опирается на снимок прочитанного с якорями вида `[ФАЙЛ#ТЕГ]`. Режим
  задан `edit.mode: hashline` с `enforceSeenLines: true` (проверено в конфиге
  станции).
- `read` код без селектора возвращает структурную сводку с футером, который
  называет селектор для дочитывания элидированных диапазонов (проверено в
  сессии); тело дочитывай повторным `read` с этим селектором, а не сплошным
  чтением файла.
- Советник (Advisor) — параллельный агент omp: включается `advisor.enabled`,
  советы приходят в сессию блоками вида `<advisory severity="blocker">`,
  модель задаёт `modelRoles.advisor`. Среду опознавай по системному промпту и этому
  справочнику.
- Транскрипт сессии — `~/.omp/agent/sessions/<slug каталога>/<метка UTC>_<id>.jsonl`
  (записи `message` и `custom_message`). Рядом одноимённый каталог: там лежат
  `__advisor.jsonl` — транскрипт советника, `<Имя>.jsonl` — прогоны субагентов
  и `<N>.bash.log` — выводы bash. Причину недоставленного результата ищи
  здесь; прочитанное — диагностика: гейт доставки оно не закрывает и файл
  результата не заменяет.
