# Разметка комментариев

Текст готовится в нативной разметке продукта. Клиент `scripts/tracker.py` при
чтении конвертирует её в markdown (`[text|url]` → `[text](url)`, `_` может
съедаться как emphasis), поэтому вид прочитанного комментария образцом для
нового не является.

## Jira

Комментарии — Jira wiki markup, не markdown.

- Заголовки — `h3.`; markdown-таблицы (`|…|`) не поддерживаются.
- Нумерованный список верхнего уровня — `1.`, `2.`; вложенный пункт — два
  пробела отступа и `- `.
- Ссылка — `[текст|URL]`, название страницы в ёлочках:
  `[«Профиль паблишера»|https://<wiki>/pages/viewpage.action?pageId=19961680]`.
  Сразу после ссылки текстом укажи место: `разделы «Создание паблишера»`,
  `строка «Создать паблишера»`.
- Параметр пути в фигурных скобках экранируй обратным слэшем перед `{`,
  закрывающую не трогай: `PUT /api/v1/publishers/\{id}/activate` — иначе
  wysiwyg-редактор рвёт `{…}` как макрос.
- Inline-идентификаторы — в backticks.
