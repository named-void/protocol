# Адаптеры

Используй область для чтения и явно разрешённой записи во внешние системы.
Прочитай только выбранный `SKILL.md`.

| Ситуация | Навык |
|---|---|
| Issue tracker: задачи, поиск, личный список, статусы | `issues/SKILL.md` |
| VCS host: доступ к MR/PR и репозиторий задачи | `vcs/SKILL.md` |
| Wiki: страницы, поиск, комментарии, поиск спецификации | `wiki/SKILL.md` |
