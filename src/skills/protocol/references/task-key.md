# Ключ задачи без своего ключа в трекере

Задаче без своего ключа в трекере ключ выделяется от того, к чему она относится, а не из общей нумерации:

1. База: ключ задачи-источника, из которой работа выделена, то есть задачи той ветки или того MR (`UPL-940`). Он берётся из `origin` выделенной работы.
   Ветка источника может быть ещё не запушена: на выбор базы это не влияет. Источник, названный MR, разрешай через `adapter-vcs`.
2. Базой служит имя рабочего каталога репозитория (`ord-service`), только когда источника нет вовсе: работа не выделена ни из какой задачи и `origin` у неё пуст.

Индекс к базе выдели командой `python3 "$PROTOCOL_SRC/lib/skills_config.py" allocate-task-key <база> --path "$WORK_ROOT"`: он продолжает максимальный уже видимый индекс этой базы в каталогах задач, ветках, worktree и заголовках коммитов.
  Выделение идемпотентно до создания `TASK_DIR`, поэтому ключ занимает именно созданный каталог.

Производный ключ наследует регистр базы: `UPL-940-6` остаётся в верхнем, `ord-service-1` в нижнем.
